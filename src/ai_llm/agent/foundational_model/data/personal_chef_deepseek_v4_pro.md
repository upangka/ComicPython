## 🍮 为您推荐：**法式焦糖布丁（烤布丁）**

您手头有 **3个全蛋 + 1个蛋黄**，这个配方简直是为您量身定做的！烤布丁的经典配方恰好就是「3个全蛋 + 1个蛋黄」，多出来的蛋黄能让布丁口感更加**浓郁顺滑、入口即化**。

---

### 📝 所需食材

| 食材 | 用量 |
|------|------|
| 鸡蛋（全蛋） | 3个 |
| 蛋黄 | 1个 |
| 牛奶 | 320g |
| 白砂糖 | 20g |
| 蜂蜜（可选） | 5g |
| 香草精/香草荚（可选） | 少许 |

> 如果家里没有香草精和蜂蜜，只用**鸡蛋+牛奶+糖**也完全可以做！

---

### 👨‍🍳 做法步骤

1. **混合蛋液**：将3个全蛋和1个蛋黄打入大碗中，加入白砂糖和蜂蜜，搅拌均匀（不要过度打发，避免产生太多气泡）。

2. **加热牛奶**：将牛奶加热至约60°C（温热不烫手，锅边冒小泡即可）。

3. **融合**：将热牛奶缓缓倒入蛋液中，一边倒一边搅拌，混合均匀。

4. **过筛**：将混合液过筛1-2次，这一步很重要，能滤掉蛋筋和气泡，做出来的布丁才细腻嫩滑。

5. **装模**：将布丁液倒入耐热模具中，装至八分满。用锡纸封住模具顶部，戳几个小洞。

6. **水浴烘烤**：将模具放入烤盘，烤盘中倒入热水（水位到模具一半高度）。烤箱预热150°C，中层烤约**35-40分钟**。

7. **出炉冷藏**：烤好后取出放凉，再放入冰箱冷藏2小时以上，口感更佳！

---

### ✨ 小贴士

- **没有烤箱？** 也可以用蒸锅隔水蒸，小火蒸约15-20分钟，同样嫩滑。
- **判断熟度**：用牙签插入布丁中心，拔出来干净不带蛋液就熟了。
- 冷藏后表面可以撒一层白糖，用喷枪烤成焦糖面，就是经典的**焦糖布丁（Crème Brûlée）**啦！
